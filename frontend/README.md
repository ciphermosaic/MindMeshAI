# MindMeshAI

MindMeshAI helps students organize assignments, deadlines,
and important messages from connected communication platforms.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Requirements

- Node.js
- npm

## Setup

Install dependencies:

```bash
npm install
```

Create a `.env` file using `.env.example` and configure
the backend API URL.

## Run Locally

```bash
npm run dev
```

## Build

```bash
npm run build
```
